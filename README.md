# Jujishou测试

零依赖的浏览器抽卡小游戏：纯静态 HTML / CSS / JS，没有构建步骤、没有 npm、没有框架。

线上地址：<https://jujishou.github.io/jujishou/>

## 两个卡池

站内有两套互相独立的卡池，保底进度分别计算，卡面只用 5 张自备立绘。

### 卡池一 · 夜瞳（限定）

| 档位 | 出率 | 卡面 |
| --- | --- | --- |
| **UR（大隐藏）** | 0.3% | 夜瞳 |
| SR | 5.1% | 蓝耳机 |
| R | 94.6% | 永远怀念 |

### 卡池二 · 方块（限定）

| 档位 | 出率 | 卡面 |
| --- | --- | --- |
| **UR（大隐藏）** | 0.3% | 方块白 |
| R | 99.7% | 橘座 |

> 卡池二没有 SR 卡，所以 SR 的概率直接并入 R，十连保底 SR 在这一池自动关闭。

## 保底规则

- **大隐藏硬保底**：同一卡池累计 120 抽必出 UR，出货后计数归零。
- **十连保底**：同一卡池连续 10 抽必出 SR 及以上（卡池二没有 SR，此规则不适用）。
- 两个卡池的保底各算各的，互不影响。

因为硬保底的存在，大隐藏的实际出率约 **0.97%**，高于标称的 0.3% —— 页面统计里显示的是实际滚出来的值。

## 大隐藏的遮罩

UR 卡在第一次获得之前，卡面显示成灰度 + `???`。首次抽到之后永久解锁真名与彩色立绘。

## 后台

页面底部有「后台」按钮，输入专属密钥即可进入控制台：

- **服务器状态**：在线玩家数、占用字节、总抽数、服务器时间、监听端口（每 5 秒自动刷新）
- **玩家存档**：服务端上每一份存档的 id、大小、抽数，可展开看原始 JSON
- **审计日志**：每一次请求的时间、IP、方法、路径、状态码
- **本机存档管理**：导出存档 JSON、导入存档、重置本池保底、清空全部数据
- **原始存档**：实时显示本机 `localStorage` 里的完整 JSON

站内有两套部署形态，前端会自动分辨：

| | 静态托管（GitHub Pages） | 服务端（自己的云服务器） |
| --- | --- | --- |
| 后台入口 | 探测不到 `/api/health`，按钮自动隐藏 | 显示，需服务端密钥 |
| 密钥校验 | —— | 服务端 PBKDF2(120000 轮)，前端改不动 |
| 存档 | 只在本机 `localStorage` | 服务端 `saves/<id>.json`，换设备自动认领 |
| 审计 | 无 | 有，落 `access.log` |

## 服务端

服务端是 [`server/`](server/) 里一份零依赖的 C 程序，交叉编译成静态二进制后部署，
详见 [server/README.md](server/README.md)。它会：

- 用 `<id>.<过期时间>.<HMAC-SHA256>` 签会话 Cookie，后台 Cookie 是 `HttpOnly` + `SameSite=Strict`
- 密钥以 PBKDF2-SHA256 加随机盐存盘，前端只把「密钥的 SHA-256」发出去，明文永不出浏览器
- 拒绝畸形 JSON、路径穿越（含 `%2e%2e`、`..%2f` 等编码变体）、跨玩家读写存档
- 同一 IP 十分钟内失败 5 次即限速，并记录审计日志

### 换密钥

在服务器上执行：

```sh
printf '%s' '新明文密钥' | sha256sum | awk '{print $1}'   # 得到 cred
/opt/gacha/gachad initkey <刚才的 cred>
/opt/gacha/start.sh                                        # 重启
```

旧密钥立刻失效，不必改任何前端代码。

## 存档

服务端在线时，进度同时存在服务端与本机 `localStorage`（键 `starfall-gacha-v2`）：
本机为空时会自动认领服务端那份，所以换设备也能接着抽；本机已有进度则以本机为准。
纯静态托管时只存在 `localStorage`，换设备需要用后台的导入 / 导出搬运。

## 本地预览

纯前端部分：

```bash
cd gacha-site
python3 -m http.server 8080
# 打开 http://localhost:8080
```

带服务端（后台可用）：

```bash
cd gacha-site/server && ./build.sh /tmp/gachad && cd ..
/tmp/gachad initkey "$(printf '%s' '你的密钥' | sha256sum | awk '{print $1}')"
GACHA_PORT=8080 GACHA_WWW="$PWD" GACHA_DATA=/tmp/gacha-data /tmp/gachad
```

前端用的是相对路径（`api/health`、`api/save`），所以挂在任何子路径下都能正常工作。
